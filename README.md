## 🛠️ Core Technical Tracks

### 1. Systems, Network Internals & Offensive Security
* Linux internals, privilege escalation, and command-line automation.
* Network packet inspection, socket programming, and protocol manipulation.
* Web, API, and IoT vulnerability exploitation (OWASP Top 10, PortSwigger Labs, CTF/Wargame write-ups).

### 2. AI for Cyber Defense (Detection Engineering)
* Automated log parsing, threat hunting, and anomaly detection using Python (`Pandas`, `NumPy`, `Scikit-Learn`, `PyTorch`).
* Building and evaluating Machine Learning classifiers for network intrusion detection (NIDS), malware analysis, and phishing detection with a focus on minimizing false positives.

### 3. Security of AI (Adversarial ML & LLM Red-Teaming)
* **Adversarial Machine Learning:** Evasion attacks, data poisoning, and model hardening.
* **LLM & Agent Security:** Prompt injection, indirect prompt injection, jailbreaking, and securing autonomous AI pipelines (OWASP Top 10 for LLMs / MITRE ATLAS).
